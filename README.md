Шаблон системного репозитория-агрегатора для проектов аппаратного обеспечения.

Используйте этот шаблон для создания репозитория-агрегатора для вашего 
проекта аппаратного обеспечения.

## Лицензия

Шаблон распространяется под лицензией **Creative Commons CC-BY 4.0**, согласно которой
вы можете свободно делиться данным шаблоном и адаптировать его под свои нужды, при 
условии указания авторства (подробнее см. файл LICENSE).

## Внимание

Лицензия в этом репозитории относится к самому шаблону, при создании своего
проекта на основе данного шаблона, замените текст лицензии на необходимый вам.

Текст этого файла описания также замените на ваш.

## Описание каталогов и файлов

- `Docs/` - документация вашего проекта (руководства, схемы, спецификации, BOM и т.д.)
- `Manifests/` - манифест-файлы для всех версий вашего проекта
- `Tools/` - Вспомогательные утилиты и скрипты (проверка манифест-файла, клонирование репозиториев и т.п.)
- .gitignore - gitignore-файл
- LICENSE - лицензия (замените на требуемую)
- README.md - данный файл описания проекта

Данная структура репозитория основана на соглашении по разработке аппаратного обеспечения.

Вы можете изменять данную структуру в соответствии с вашими задачами.

Каталоги репозитория-шаблона содержат файлы-заглушки `.gitkeep`, удалите их после того, как 
вы заполните соответствующий каталог файлами.
